# HMS-AI-ROUTER v25.75 — Runbook evidence Windows + Codex thật

Ngày cập nhật: 2026-08-24

## Mục tiêu và ranh giới

Runbook này tạo và review evidence cho đúng 7 runtime case canonical:

`host`, `codex`, `quota`, `failover`, `lan`, `soak_6h`, `soak_24h`.

Không bước nào tự nâng production score, tự chứng nhận Windows, tự merge upstream hoặc tự bật real effects. `soak_6h` và `soak_24h` phải là active-process time thật; synthetic evidence hoặc clock manipulation không hợp lệ.

## 1. Điều kiện máy đích và certificate preflight

Yêu cầu:

- Windows + Windows PowerShell 5.1.
- Codex CLI hiện hành; `codex --version` chạy thành công.
- Ít nhất 2 managed Codex instances tách project, `CODEX_HOME`, account identity và port.
- Evidence quota thật/fresh cho tối thiểu 2 account.
- Bounded failover test đã restore thành công.
- Tối thiểu 2 LAN node signed/online và shared-path roundtrip PASS.
- Real soak 6h và 24h đủ active elapsed time.
- Python có package `cryptography`.
- Certificate RSA dành riêng cho evidence signing nằm trong `Cert:\CurrentUser\My`.

Chạy read-only certificate preflight:

```powershell
python _runtime\HMS_Codex_ExternalWindowsCertificatePreflight.py `
  --certificate-thumbprint "<THUMBPRINT>"
```

Expected: `ready = true`.

Preflight này **không ký**, **không sửa certificate store**, **không export private key**. Nó kiểm exact thumbprint, certificate validity, RSA private-key accessibility, DigitalSignature KeyUsage nếu extension tồn tại, CA constraint, DER SHA-256 và pseudonymous signer ref.

Nếu preflight fail thì dừng trước khi thu evidence dài hạn.

## 7. Reviewer tạo trust authority độc lập

Reviewer phải có **trust store đã được phê duyệt qua kênh độc lập/out-of-band**, không được xây trust store bằng cách copy certificate/trust snapshot từ packet đang review.

Đặt reviewer state:

```powershell
$ReviewState = "$env:LOCALAPPDATA\HMS-AI-ROUTER\promotion-review"
New-Item -ItemType Directory -Force -Path $ReviewState | Out-Null
```

Tạo sealed reviewer trust authority:

```powershell
python _runtime\HMS_Codex_ReviewerTrustAuthoritySnapshot.py --capture `
  --trust-store "<REVIEWER_APPROVED_TRUST_STORE.json>" `
  --authority "$ReviewState\reviewer_trust_authority_v2575.json" `
  --integrity-key "$ReviewState\reviewer_local_integrity.key.dpapi"
```

Expected: `TRUST_AUTHORITY_CAPTURED`.

Authority chứa approved `trust_snapshot_sha256`, trust-store generation và metadata các ACTIVE pins. Nó phải có `packet_derived=false` và được HMAC-seal bằng key được bọc Windows DPAPI machine-scope.

Mặc định authority chỉ fresh 24 giờ. Nếu chuyển sang máy reviewer khác, không copy DPAPI key để bypass; phải capture/re-authorize authority trên máy đó.

## 9. Human review

Mở HMS-AI-ROUTER qua launcher principal và vào `Promotion review`.

Các gate bắt buộc:

- `Evidence`: verified packet thật.
- `Signature`: cryptographic certificate verification PASS.
- `Trust`: sealed reviewer authority hợp lệ + independent trust anchor match.
- `Freshness` và `Idempotency`: PASS.
- Live Cockpit baseline được recheck khi mở và ngay trước reviewer action.
- Hai reviewer độc lập/pseudonymous cho các lane bắt buộc.

Nếu local verified metadata seal hỏng, GUI hiển thị BLOCK và không chạy reviewer action. Baseline drift biến `APPROVE`/`REJECT` thành `INVALIDATE`.

Ingest/runner/controller vẫn không tự tăng production score và không tự chứng nhận Windows.

## 10. Các trường hợp phải dừng

Dừng và sửa nguyên nhân nếu gặp bất kỳ trường hợp nào:

- certificate preflight fail;
- selected certificate không phải ACTIVE pin;
- certificate/trust store thay đổi giữa preflight và signing;
- signer tự khai báo hoặc signature/payload tamper;
- certificate revoked/retired/expired/not-yet-valid/unpinned;
- trust snapshot hoặc signer-ref mismatch;
- reviewer trust authority stale, unsealed, packet-derived hoặc digest mismatch;
- verified metadata/replay registry local seal invalid hoặc DPAPI key unavailable;
- arbitrary/missing/duplicate seven-case IDs hoặc case digest mismatch;
- stale/replayed packet;
- synthetic/local-only evidence;
- thiếu Windows/Codex hoặc soak chưa đủ active time;
- Cockpit baseline drift.
