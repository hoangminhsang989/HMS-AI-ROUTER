# HMS-AI-ROUTER v25.75 — Runbook evidence Windows + Codex thật

Ngày: 2026-08-23

## Mục tiêu và ranh giới

Runbook này tạo **review packet** cho 7 runtime case canonical:

`host`, `codex`, `quota`, `failover`, `lan`, `soak_6h`, `soak_24h`.

Không bước nào trong runbook tự nâng production score, tự chứng nhận Windows, tự merge upstream hoặc tự bật real effects. `soak_6h` và `soak_24h` phải là thời gian active-process thật; không được rút ngắn bằng synthetic/clock manipulation.

## 1. Điều kiện máy đích

- Windows + Windows PowerShell 5.1.
- Codex CLI hiện hành; `codex --version` chạy thành công.
- Ít nhất 2 managed Codex instances tách project, `CODEX_HOME`, account identity và port.
- Evidence quota thật/fresh cho tối thiểu 2 account.
- Bounded failover test đã restore thành công.
- Tối thiểu 2 LAN node signed/online và shared-path roundtrip PASS.
- Real soak 6h và 24h đủ active elapsed time.
- Python có package `cryptography`.
- Có certificate RSA với private key trong `Cert:\CurrentUser\My` dùng riêng cho evidence signing.

Kiểm tra certificate:

```powershell
Get-ChildItem Cert:\CurrentUser\My | Select-Object Thumbprint, Subject, HasPrivateKey, NotBefore, NotAfter
```

Không copy/export private key vào repo hoặc packet.

## 2. Enroll certificate vào trust store

Chạy bằng thao tác operator có chủ đích:

```powershell
python _runtime\HMS_Codex_ExternalWindowsCertificateEnrollment.py `
  --trust-store "$env:LOCALAPPDATA\HMS_AI_MultiRouter\external-evidence-trust-v2575.json" `
  --certificate-thumbprint "<THUMBPRINT>"
```

Expected: `CERTIFICATE_PINNED`.

Enrollment ký một challenge được đánh dấu `NOT_EVIDENCE`, tự verify certificate rồi pin `certificate_sha256 + pseudonymous signer ref + validity` vào trust store. Private material không được xuất.

Nếu certificate bị compromise, revoke pin bằng trust-store workflow trước khi tạo packet mới. Packet sử dụng pin `REVOKED`, `RETIRED`, chưa valid hoặc hết hạn sẽ bị quarantine.

## 3. Thu evidence thật cho Target-Machine Certification

Real Codex minimum vẫn theo runbook authority `_runtime/REAL_CODEX_CERTIFICATION_RUNBOOK_V25.49.md`: preflight trước, sau đó operator xác nhận live request có giới hạn. PASS live phải là `PASS_REAL_CODEX_CERTIFIED`.

Sau khi có real-Codex evidence, quota snapshot, failover evidence, LAN snapshot/shared path và soak files, chạy target runner v25.53:

```powershell
python _runtime\HMS_Codex_TargetMachineCertification.py `
  --real-cert-evidence "<REAL_CODEX_EVIDENCE.json>" `
  --quota-snapshot "<QUOTA_SNAPSHOT.json>" `
  --failover-evidence "<FAILOVER_RESULT.json>" `
  --lan-snapshot "<LAN_SNAPSHOT.json>" `
  --shared "<SHARED_PATH>" `
  --soak6-evidence "<SOAK_6H.json>" `
  --soak24-evidence "<SOAK_24H.json>" `
  --output "<WORK_DIR>\target-machine-certification.json"
```

Chỉ tiếp tục khi report có đồng thời:

- `verdict = PASS_TARGET_MACHINE_PRODUCTION_CERTIFIED`
- `production_certification = TARGET_MACHINE_WINDOWS_CODEX_LAN_SOAK`
- `summary.stages_pass = 7`
- chính xác 7 stage canonical đều `pass=true`.

## 4. Export đúng 7 case report

Không tự tạo/tách JSON bằng tay:

```powershell
python _runtime\HMS_Codex_ExternalWindowsCaseReportExporter.py `
  --source "<WORK_DIR>\target-machine-certification.json" `
  --output-dir "<WORK_DIR>\cases"
```

Exporter fail-closed nếu source chỉ partial, thiếu stage hoặc không đúng exact set. Mỗi case report bind `source_report_sha256` của report 7/7 gốc.

## 5. Preflight packet

Chuẩn bị ZIP gói release và release manifest đúng build cần review, sau đó:

```powershell
python _runtime\HMS_Codex_ExternalWindowsEvidenceRunner.py --preflight `
  --package-zip "<PACKAGE.zip>" `
  --release-manifest "<RELEASE_MANIFEST.json>" `
  --trust-store "$env:LOCALAPPDATA\HMS_AI_MultiRouter\external-evidence-trust-v2575.json" `
  --certificate-thumbprint "<THUMBPRINT>" `
  --case-report "host=<WORK_DIR>\cases\host.json" `
  --case-report "codex=<WORK_DIR>\cases\codex.json" `
  --case-report "quota=<WORK_DIR>\cases\quota.json" `
```

Expected: `ready=true`. Preflight chỉ đọc/kiểm tra prerequisites; không tạo synthetic evidence và không ký packet.

## 6. Tạo certificate-signed review packet

Bỏ `--preflight`, thêm output:

```powershell
python _runtime\HMS_Codex_ExternalWindowsEvidenceRunner.py `
  --package-zip "<PACKAGE.zip>" `
  --release-manifest "<RELEASE_MANIFEST.json>" `
  --trust-store "$env:LOCALAPPDATA\HMS_AI_MultiRouter\external-evidence-trust-v2575.json" `
  --certificate-thumbprint "<THUMBPRINT>" `
  --case-report "host=<WORK_DIR>\cases\host.json" `
  --case-report "codex=<WORK_DIR>\cases\codex.json" `
  --case-report "quota=<WORK_DIR>\cases\quota.json" `
  --case-report "failover=<WORK_DIR>\cases\failover.json" `
  --case-report "lan=<WORK_DIR>\cases\lan.json" `
  --case-report "soak_6h=<WORK_DIR>\cases\soak_6h.json" `
  --case-report "soak_24h=<WORK_DIR>\cases\soak_24h.json" `
  --output "<WORK_DIR>\HMS_EXTERNAL_WINDOWS_CODEX_REVIEW_PACKET.json"
```

Expected: `PACKET_READY_FOR_HUMAN_REVIEW` và `ingest_precheck = PASS`.

Signature bind toàn bộ promotion-relevant packet payload, gồm package SHA-256, manifest SHA-256, Cockpit parity baseline, capture/run/nonce IDs, trust snapshot và exact 7 case report digests. Packet sửa sau khi ký sẽ bị reject.

External packet chỉ chấp nhận `WINDOWS_CERTIFICATE_SIGNATURE`. DPAPI local-machine HMAC không đủ cho independent external review và bị chặn.

## 8. Các trường hợp phải dừng

Dừng và sửa nguyên nhân nếu gặp bất kỳ trường hợp nào: signer tự khai báo; certificate không pinned/revoked/expired; trust snapshot hash mismatch; signer-ref mismatch; packet/case digest mismatch; arbitrary seven IDs; stale/replayed packet; synthetic/local-only evidence; thiếu Windows/Codex; soak thiếu thời gian thật; baseline drift.
