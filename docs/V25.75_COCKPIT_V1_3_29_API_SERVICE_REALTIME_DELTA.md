## Source-level safety boundaries

The exact v1.3.29 source shows these boundaries:

- Live handlers require a Cockpit API key.
- Realtime handlers share an API-key guard.
- Provider-gateway API keys are rejected for Codex Live and Realtime rather than silently routed into an unsupported provider.
- If the Codex Live backend handler is unavailable, the sidecar returns service-unavailable rather than attempting an alternate mutation path.
- Existing Responses WebSocket safety remains separate from the new Live/Realtime matrix and keeps explicit enablement/provider-gateway guards.

Upstream v1.3.29 tests include route smoke coverage for Live sideband and Realtime calls; the pre-existing Responses WebSocket tests continue to cover disabled-by-default and provider-gateway rejection behavior.
